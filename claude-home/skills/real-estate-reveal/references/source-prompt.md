---

Build me an award winning cinematic luxury real estate website for a high end property.

I will provide the property images.

Use those images as the full visual source of truth.

The entire website should feel like one continuous scroll driven journey through the home.

The experience should begin outside the property, move naturally through the interior, and end with a full backyard and pool reveal.

The site should feel like a private architectural film, not a normal real estate listing website.

## INPUTS I WILL PROVIDE

I will provide:

Property name or address
Location
Price
Property facts such as square footage, bedrooms, bathrooms, lot size, and other key features
Listing agent details
A set of real property images

The images may include:

Front exterior
Entry
Main living area
Kitchen
Dining area
Primary suite or strongest interior space
Rear exterior
Pool
Backyard
Any other standout feature

## SOURCE OF TRUTH

Use my images and property details as the source of truth.

Do not invent architecture.
Do not invent views.
Do not invent materials.
Do not invent rooms.
Do not invent layout connections that do not make sense.
Do not redesign the house.
Do not turn it into a different property.

Preserve the real furniture, finishes, proportions, landscaping, and spatial feel shown in the images.

## HIGGSFIELD MCP

Use the Higgsfield MCP for all cinematic image to video generation.

Use the most cinematic model available.

Use my supplied images as anchors for every generated sequence.

The clips must feel visually connected so the same property remains consistent from start to finish.

Create motion that feels calm, expensive, and believable.

Use slow camera movement.

Use subtle environmental motion such as moving light, reflections, trees, curtains, or water when appropriate.

No audio.

All clips should be 16:9.

## CORE IDEA

This website should work like a cinematic walkthrough.

Scrolling should move the visitor through the property.

The user should feel like they are physically traveling through the house.

The journey starts at the front exterior.
Then it approaches the home.
Then it moves inside.
Then it passes through the main interior spaces.
Then it exits toward the outdoor area.
Then it ends with a full pool and backyard reveal.

## WEBSITE STRUCTURE

Build the website in 6 sections.

Each section should feel like a chapter in one continuous story.

### 1. FRONT EXTERIOR HERO

Start with the strongest front exterior image.

Use Higgsfield to create a slow cinematic push toward the property.

This is the first impression.

Show only minimal copy such as:

[Property Name or Address]
[Location]
[Price]

Optional short line such as:

A private residence in [Location]

Use full screen imagery.

Keep text minimal.

This section should make the property feel important immediately.

### 2. APPROACH AND ENTRY

Continue the journey by moving toward the entrance.

Then move into the home in a believable way.

If the image set supports it, create a smooth transition from outside to inside.

Use this section to introduce the residence with a few short facts such as:

[Square Footage]
[Bedrooms]
[Bathrooms]
[Lot Size]

Keep the copy short.

The visual journey matters more than the text.

### 3. MAIN LIVING EXPERIENCE

Move through the main living spaces.

Use the best connected interior images, such as the living room, great room, or open concept entertaining area.

Create a slow cinematic glide through the space.

Reveal only a few short details tied to what the viewer is seeing.

Examples:

Expansive living area
Floor to ceiling glass
Indoor outdoor flow
Custom architectural details

Only use details that are actually true for the property.

### 4. KITCHEN OR SIGNATURE INTERIOR FEATURE

Feature the strongest interior moment.

This may be the kitchen, dining room, primary suite, or another standout space.

Use this section as the interior hero moment.

Let the camera slow down.

Allow the visual to breathe.

Show a few specific callouts based on the actual home.

Examples:

Custom cabinetry
Stone surfaces
Chef's kitchen
Panoramic views
Spa style bath

Again, only use real features confirmed by the images or property details.

### 5. TRANSITION TO OUTDOOR LIVING

Begin moving toward the rear of the property.

Build anticipation for the outdoor reveal.

Show the connection between inside and outside.

Approach the rear doors, terrace, or opening to the backyard.

Do not reveal the full pool or yard too early.

Use this section to highlight lifestyle features such as:

Entertaining spaces
Covered patio
Outdoor dining
Seamless indoor outdoor living

Only if those features are actually present.

### 6. POOL AND BACKYARD FINALE

Finish with the biggest visual payoff.

Reveal the pool and full backyard.

This should be the strongest and widest ending shot.

Use Higgsfield to create elegant motion in the water, landscaping, and lighting.

Let this section breathe.

This is where the private showing call to action appears.

Overlay:

Experience the Residence
Private showings by appointment

Then show:

[Agent Name]
[Agent Phone]
[Agent Email]
[Request Private Showing Button]

Include a simple form with:

Name
Email
Phone
Preferred Showing Date
Message

Keep the backyard visible behind the form.

## DESIGN DIRECTION

The design should feel expensive, quiet, and editorial.

Use the property itself to guide the visual tone.

Do not make every property look black and gold by default.

Pull tones from the home and photography.

Use a refined serif for large headlines.

Use a clean sans serif for small details.

Use lots of negative space.

Use very few words.

Large imagery should lead the experience.

Avoid template looking cards and generic real estate site styling.

This should not feel like Zillow, Redfin, or a normal brokerage site.

## SCROLL AND MOTION

Use scroll as the main control system.

Scrolling down should move the visitor forward through the residence.

Scrolling up should move them backward through the journey.

Use Lenis for smooth scrolling.

Use GSAP ScrollTrigger for scroll tied animation.

Use frame scrubbing or video scrubbing where needed for a smooth cinematic feel.

Transitions between sections should feel connected.

Avoid harsh cuts when possible.

The site should feel like one flowing property story.

## COPY STYLE

Keep the copy short, quiet, and specific.

Do not use generic luxury phrases.

Avoid empty claims.

Use facts and visual mood.

Let the property do the selling.

## REUSABILITY

This prompt should work for any luxury real estate property as long as I provide the correct images and property facts.

When building each version, study the supplied images first and decide the most believable journey from front exterior to backyard reveal.

If the exact room order changes from one property to another, adapt the walkthrough while keeping the same 6 section structure.

## FINAL VERIFICATION

Launch the website locally.

Open it in the browser.

Scroll from the exterior all the way through the home and out to the backyard.

Then scroll back in reverse.

Verify that the journey feels smooth and visually consistent.

Check that the same property identity is preserved throughout.

Check that transitions make sense.

Check that text appears at the right moments.

Check desktop and mobile.

Fix any broken transition, impossible camera jump, loading issue, frame stutter, or layout issue before saying the site is complete.
