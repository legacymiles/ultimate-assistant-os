The owner said all their sites look boring. From 2026-09-20, a design skill fires on **every**
build of a user-facing interface — new app, new page, hero, dashboard, visual overhaul — without
them asking, chosen before any UI code is written, and named out loud.

Defaults they picked (both free, pure code, no API spend):
- **App / tool / product UI** (hub apps, dashboards, databases, forms) → `impeccable`
- **Landing page / hero / portfolio / public-facing** → `taste-skill` (design-taste-frontend)

Opt-in only, never auto-invoked because they cost money or render footage: `h3-scroll-world`,
`scroll-world`, `scroll-craft`, `real-estate-reveal`, `imagegen-frontend-web`,
`imagegen-frontend-mobile`, `image-to-code-skill`, `blender-to-web`.

**Why:** their portfolio apps were coming out looking like default Tailwind templates, and the
skills that would fix that were sitting unused unless they remembered to name one. The free-only
constraint is theirs — the scroll-video route burns muapi/H3 credits per build.

**How to apply:** invoke the skill first, announce it ("Using `impeccable` for the UI"), and swap
to another free skill (`interactive-web-studio`, `cinematic-ui`, `brutalist-skill`,
`minimalist-skill`, `soft-skill`, `ui-ux-pro-max`, `redesign-skill`) only when the brief clearly
calls for it or they name it. Written into both the global and project CLAUDE.md. Pairs with
[[ai-rankings-app]] (they want dense database UIs, not card grids) and [[gauntlet-loop-skill]]
for pushing a build past the quality bar.
