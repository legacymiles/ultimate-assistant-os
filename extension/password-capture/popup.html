Checking the agent…
The key is held in memory by the local agent, never written to disk.
Only the username is shown. The password is fetched at the moment you click Fill.
The local agent is not running, so nothing can be saved or filled.
Start it on the PC, then reopen this popup:
npm run passwords:agent
Leave that window open. Closing it drops the key from memory.
Capture is automatic once unlocked. Localhost is never captured.
