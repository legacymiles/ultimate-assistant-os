# Music Creator — the SERVER's own dependencies, and only those.
#
# The models are not in here on purpose. YuE2 wants Python 3.12, AuK wants
# 3.10, and SheetSage2 wants 3.10/3.11 with FFmpeg 6.1 beside it; one
# requirements file cannot describe all three, and pip would spend an hour
# proving it. Each model is installed from its own repo into its own venv
# (see README.md), and the server reaches the ones it cannot import with
# --yue2-python / --auk-python / --sheetsage-python.
#
# So this file is deliberately tiny: everything else the server needs is in
# the standard library, and ffmpeg is a system package, not a wheel.
#
#   python -m pip install -r tools/music-creator/requirements.txt
#
# Demucs is the one near-exception: four-stem separation is an ordinary pip
# install with no version fight in it, so `pip install demucs` into this venv
# is usually enough. It is still left out of this file deliberately, because a
# server that only writes songs should not be made to download it -- and the
# stem rack in the website reports it as missing rather than breaking without
# it. See README.md, "Stems".
#
